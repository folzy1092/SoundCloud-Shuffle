# SoundCloud Shuffle by Folzy

Полное перемешивание лайков SoundCloud для Chromium-браузеров.

Обычный Shuffle SoundCloud может работать только с уже подгруженной частью очереди. Это расширение синхронизирует все доступные треки из **Likes**, перемешивает весь набор алгоритмом Fisher–Yates и подменяет следующую очередь, не прерывая текущий трек.

## Возможности

- полная случайная очередь по всем доступным лайкам;
- пагинация `track_likes` через SoundCloud API v2;
- отдельный локальный кэш для каждого SoundCloud-аккаунта;
- текущий трек остаётся играть;
- очередь заменяется одной атомарной операцией `replaceQueue`;
- повторный Shuffle создаёт новую полную перестановку;
- popup со статусом синхронизации, ручным обновлением и очисткой кэша;
- русские сообщения об ошибках;
- без внешнего сервера и сторонних runtime-зависимостей;
- расширение не сохраняет пароль, cookies или OAuth-токен.

## Поддержка

Chromium-браузеры с Manifest V3:

- Brave
- Google Chrome
- Microsoft Edge
- Opera

## Установка

1. Скачай или клонируй репозиторий.
2. Открой страницу расширений браузера.
3. Включи **Режим разработчика**.
4. Нажми **Загрузить распакованное расширение**.
5. Выбери папку `extension`.
6. Полностью обнови уже открытые вкладки SoundCloud.

## Использование

1. Авторизуйся в SoundCloud.
2. Открой `https://soundcloud.com/you/likes`.
3. Включи любой доступный трек из своих Likes.
4. Нажми штатную кнопку **Shuffle** в нижнем плеере.
5. При первом запуске расширение синхронизирует Likes. Следующие клики используют локальный кэш и создают новую перестановку.

Через popup можно вручную синхронизировать лайки или очистить данные только текущего аккаунта.

## Как это работает

Архитектура разделена на три части:

- `background.js` загружает все страницы `track_likes` и атомарно сохраняет кэш в `chrome.storage.local`;
- `content.js` перехватывает штатную кнопку Shuffle до обработчика SoundCloud;
- `page-bridge.js` работает в MAIN world, получает `meUser` и `apiClient` из `window.__sc_hydration`, подключается к внутреннему player runtime SoundCloud и заменяет очередь.

Расширение поддерживает оба встречающихся селектора кнопки Shuffle: `.playControls__shuffle.playControls__control` и `.shuffleControl`.

## Данные и приватность

В `chrome.storage.local` хранится только нормализованный кэш доступных понравившихся треков и время последней синхронизации. Данные привязаны к ID аккаунта.

Расширение не отправляет пользовательские данные на сторонний сервер.

## Разработка

Требуется Node.js. В проекте нет npm-зависимостей.

Запуск всех тестов:

```bash
node --test tests/*.test.js
```

На Node 24 под Windows используется именно явный glob `tests/*.test.js`.

## Статус

Проект находится в ранней версии. SoundCloud может менять внутренний player runtime и структуру страницы, поэтому после крупных обновлений сайта bridge может потребовать адаптации.
